CYOA Project

Context

I'm currently in SEP 10 and our class were assigned to take upon a `Create your Own Adventure Project`. Me and my partner(Emely) were chosen to do a project based off `AI Apocalypse`. The point of the project was to practice using skills of git and github using IDE markdown.

Content

As stated before me and my partner were chosen to do a project using our creative thinking to make something that relates to an AI Apocalypse. We first had to create a plan so we know who will be doing what, we basically had the same amount of work. We did a little of communications on Slack so we could come up with an idea we both liked, as we worked we ensured that we had the requirements for a 100%.

Reflection

Our teacher Mr. Mueller assigned us the project to show understanding of git and github by using our skills in IDE to create a project. Although I wouldn't say that the communication was bad, it was pretty tough because besides from texting on slack we didn't really communicate well in-person. This was pretty difficult because we both weren't able to share ideas we had to each other. This is a crucial part of doing projects because if you don't have good communication you can't overcome challenges that occured during the project, this will be something that I'll remember when doing another project next time.
